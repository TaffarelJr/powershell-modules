# Changelog

## 0.1.0

Initial release: indent-aware line printers
(`Write-Success`, `Write-Skip`, `Write-Warn`, `Write-Failure`, `Write-Info`, `Write-Detail`, `Write-Field`, `Write-Doing`, `Write-Done`),
step tracking (`Write-Step`, `Clear-Step`, `Get-CurrentStep`),
box drawing (`Write-Header`, `Write-Banner`),
and the indent primitives (`Push-Indent`, `Pop-Indent`, `Get-Indent`,
`Invoke-Indented`).
