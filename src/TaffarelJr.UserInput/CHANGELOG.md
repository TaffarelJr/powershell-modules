# Changelog

## 0.1.0

Initial release: prompting primitives (`Read-Input`, `Read-Secret`),
validation (`Assert-Input`), environment-variable access
(`Get-EnvironmentVariable`, `Set-EnvironmentVariable`), bounded retry
(`Invoke-InputRetry`), confirmation (`Confirm-Input`, `Confirm-Proceed`),
menu selection (`Select-Choice`), and host-interactivity detection
(`Test-InteractiveHost`, `Wait-KeyPress`).
